# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.2.x   | :white_check_mark: |
| 3.1.x   | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

We take the security of EduBoard very seriously. If you discover a vulnerability or security risk, please do not disclose it publicly via GitHub Issues.

Instead, please report security concerns by emailing:
`security@eduboard.app`

Include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept payload.
3. Affected components (Web, Mobile, Cloud Firestore, API).
4. Potential impact.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible patch and release.
